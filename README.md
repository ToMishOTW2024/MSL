# mslearn-ai-language

This repository contains the lab files for the Microsoft Learn module [Develop natural language processing solutions with Azure AI Language](https://learn.microsoft.com/en-us/training/modules/develop-language-solutions-azure-ai/).

## Prerequisites

Before you begin, you will need the following:

*   An active [Azure subscription](https://azure.microsoft.com/free/).
*   [Visual Studio Code](https://code.visualstudio.com/) installed on your local machine.
*   The [Git](https://git-scm.com/) command-line interface.
*   For Python labs, you will need [Python 3.x](https://www.python.org/downloads/).
*   For C# labs, you will need the [.NET SDK](https://dotnet.microsoft.com/download).

## Getting Started

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/MicrosoftLearning/mslearn-ai-language.git
    ```
2.  **Open in Visual Studio Code:**
    Open the cloned repository in Visual Studio Code.
3.  **Follow the lab instructions:**
    Each lab has a corresponding set of instructions in the `Instructions/Exercises` directory. Navigate to the appropriate lab number to get started.
